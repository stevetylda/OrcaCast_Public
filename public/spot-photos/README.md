# Spot Photos

This folder stores curated viewing spot photos used by OrcaCast.

Rules:
- Use WebP when possible.
- Prefer 4:3 or 1:1 crops.
- Recommended card size: 320x240 or larger.
- Filename convention: `<spot-id>.webp`.
- Every photo must have an entry in `public/data/places/viewing_spot_photos.json`.
- Every photo must include source, creator, license, and source URL metadata when applicable.
- Avoid non-commercial and no-derivatives licenses.
