# App architecture and dead-code review — 2026-09-05

The working tree was clean before this review. The review covered the application entry point, lazy routes, source import graph, Vite worker imports, shared persistence and request infrastructure, dependency declarations, Python entry points, and existing validation workflows.

## Resolved findings

| Priority | Finding and consequence                                                                                                                                                                                                                                        | Resolution                                                                                                                                                                                                                                                            |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| P1       | `MapStateProvider` accessed local storage during initial render and effects, outside route error boundaries. Blocked storage or exhausted quota could prevent the entire app from rendering. Planner and itinerary persistence had similar unguarded accesses. | Added a shared best-effort browser storage adapter and routed local/session persistence through it. React state remains usable when persistence fails. Regression tests cover failed reads/writes, a denied session-storage getter, and successful persistence/reset. |
| P2       | `fetchText` cleared its timeout when response headers arrived. A stalled body download could leave consumers loading indefinitely.                                                                                                                             | Keep the abort deadline active through body consumption and clear it on every exit. A regression test first reproduced the late-body success and now verifies a timeout error.                                                                                        |
| P2       | The global map context exposed a resolution setter that intentionally did nothing and a model selection that Watch independently owned. The Watch controller also maintained state for an unrendered analyst dialog and tools drawer.                          | Removed the no-op setter, unused global model state, and obsolete controller state/handler. Resolution remains explicitly fixed at H6; Watch continues owning its model selection.                                                                                    |
| P2       | 27 source files were unreachable from the app, including the analyst grid-detail subtree, old Watch toolbar/drawer/pills/histogram/export, unused shared components/icon, and obsolete types.                                                                  | Removed the confirmed internal orphans after checking references outside the candidate set, including tests, routes, scripts, and configuration. The raster worker is retained: its `?worker` import is a live Vite entry point.                                      |
| P2       | Eight runtime dependencies and two type packages had no remaining application consumers.                                                                                                                                                                       | Removed DuckDB WASM, d3-shape, Leaflet, Plotly, PMTiles, react-leaflet, react-plotly.js, React Flow, and the d3-shape/Leaflet types. npm removed 359 installed packages. | P2       | Python packaging and Make targets advertised `src.cli`, which does not exist; environment feature flags had no consumers.                                                                                                                                      | Removed the stale `pyproject.toml`, Makefile, and feature-flag configuration. ## Validation

- Baseline: typecheck, lint, 46 unit tests and 26 component tests passed.
- Final unit/component suite: 46 unit tests and 31 component tests passed.
- Production build and initial bundle budget passed; MapLibre remains outside the initial bundle and the raster worker is emitted.
- Formatting, lint, data contracts, asset validation, repository artifact check, and build-secret scan passed.
- Source reachability recheck found no remaining unreachable non-test TypeScript modules using the inspected static/lazy/worker imports.
- Desktop/mobile Chromium: 40 passed, 6 intentionally skipped by device-specific test guards. Coverage includes direct routes, accessibility, playback, POI filters, historical rasters, media details, itineraries, and blocked-storage rendering.

## Remaining architectural considerations

`PlanPage.tsx` (about 3,200 lines), `ForecastMap.tsx` (about 2,700), and `gridOverlay.ts` (about 2,250) still combine substantial orchestration and presentation/rendering logic. Their size and shared mutable map lifecycle make changes harder to isolate. A subsequent refactor should extract planner results/itinerary presentation and map lifecycle/overlay responsibilities with targeted behavior tests. This review does not claim those modules were fully decomposed or that every CSS selector and exported member was proven live.

No forecast artifacts, scientific model contracts, or public deployments were changed. The GDAL raster-generation pipeline and remote deployment/rollback workflows were inspected only where relevant to entry-point reachability; they were not executed. Firefox and WebKit were not run.
